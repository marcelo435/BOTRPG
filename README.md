# Bot de RPG para Discord

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)
![discord.py](https://img.shields.io/badge/discord.py-5865F2?logo=discord&logoColor=white)

Bot que controla a ficha dos personagens no Discord: vida, PE e sanidade. Os comandos começam com `.` e os dados ficam salvos em `dados_rpg.json`.

## Como rodar

```bash
pip install discord.py
python bot.py
```

Antes, coloque o token do seu bot em `bot.run("")`, no fim do `bot.py`. Não envie o token para o GitHub.
